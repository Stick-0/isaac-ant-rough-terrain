# 보상 재설계 실험 계획 (실행 전 기록)

기존 Stable의 두 패널티는 새로운 지형 2개에서 생존율을 91.41% → 91.50%로 바꾸는 데 그쳤다. 따라서 단순 패널티 증량 대신 넘어짐과 위험 자세에 직접 보상을 연결한다.

## 고정 조건

- 초기 가중치: `artifacts/models/rough.pt` (원본 험지 학습 1,000회).
- 각 실행: seed 42, 4,096 환경, rollout 32, 추가 600회 = 78,643,200 transition.
- 기존 Stable과 동일한 optimizer: 새 Adam, learning rate 1e-4 고정, entropy 0.001. actor/critic와 policy std는 초기 체크포인트에서 읽는다.
- 지형, 배치, 60차원 관측, 토크 action, 16초 제한, 몸높이 0.31m 종료 기준은 동일.
- Control: 원래 7개 보상만 유지 (Stable task에서 action_rate/body_sway 가중치를 0으로 설정).
- Recovery: 새 보상 구성. 최초 실험에서는 아래 가중치를 고정한다.

## 새 보상

- 전진: 원래 목표 (1000, 0)를 향한 수평 속도, ±4.5m/s 범위로 제한. 정지는 전진 보상 0, 후진은 음수.
- 넘어짐: 사건당 -10. RewardManager가 dt를 곱하므로 함수에서 1/dt로 보정한다. 정상 시간 종료는 감점하지 않는다.
- 몸높이 위험: 지면 대비 0.48m부터 0.31m까지 정규화한 부족분의 제곱, 가중치 -2, 범위 [0, 1]. 높이 0.48m 이상은 감점 없음.
- 기울기 위험: 몸체 위쪽 벡터의 세계 수직 성분이 0.93보다 작을 때 감점, 0.5에서 포화하는 정규화 제곱, 가중치 -2.
- 기존 Stable의 action_rate -0.01, body_sway -0.025 유지.
- 원래 alive/upright/heading/effort/joint-limit 보상 유지.

## 사전에 정한 평가

- 개발 확인 지형 seed 3001; 최종 비교 지형 seed 4001, 4002.
- 지형당 512마리, noise 없는 actor, 각 개체의 첫 16초 에피소드만 집계.
- 기준 rough, 기존 stable, 원래 보상 추가 학습 control, 새 recovery를 같은 지형·초기 상태에서 비교.
- 일차 지표: 16초 생존율. 함께 제시할 지표: 종료 전 이동거리, 전진속도, 몸체 회전속도 RMS, action 변화 RMS.
- 에피소드별 결과와 초기 상태 해시를 저장한다. 개체 대응 생존/거리 차이와 불확실성을 보고한다.
- 각 실행의 마지막 체크포인트를 비교한다. 개발 결과를 보고 설정을 바꾸면 변경과 탈락 실험을 별도로 기록한다. 최종 평가를 보고 설정을 조정하면 해당 seed를 더 이상 미사용 평가라고 부르지 않는다.
- 학습 seed는 하나이므로 여러 번 재학습했을 때의 재현성까지 주장하지 않는다. 지형은 같은 생성 분포의 새로운 배치이며, 실세계나 다른 지형 분포 검증은 아니다.

## 개발 평가 후 기록

seed 3001에서 마지막 recovery 체크포인트의 생존율 92.77%, control 90.82%를 확인했다. recovery의 몸체 회전속도 RMS는 약 12.45% 낮았고, 평균 전진속도는 약 5.60% 낮았다. 최초 가중치·속도 상한·학습량·마지막 체크포인트 선택을 변경하지 않고 seed 4001/4002 최종 평가로 진행했다. 개발 결과는 최종 두 지도 평균에 섞지 않는다.
