# 공개 범위와 검증

## 포함한 자료

- 기반 커밋을 고정한 변경 코드 12개, 원본 Ant 설정 3개, 재현용 patch.
- 세 대표 모델인 평지·험지·추가 학습의 설정과 중간 실험의 보관 자료.
- 대표 모델 3개: flat, rough, recovery. 검증·재현을 위해 중간 실험 모델 4개도 유지하며 [기록 모음](archive/README.md)에서 구분한다.
- 실제 평가의 집계 JSON, TensorBoard에서 추출한 학습 곡선 CSV, 재계산 가능한 표와 그림.
- 실험 목적·지표 정의·실패·한계·재현 명령.
- 세 모델의 실제 지형·보행 영상: 평지 모델의 평지/험지 보행, 험지 모델, 추가 학습 모델 및 좌우 비교 영상·GIF. 촬영은 별도의 16환경 데모다.

모델은 실제 학습된 tensor checkpoint이며 원시 설정과 SHA-256을 [`manifest.json`](../manifest.json)에 기록했습니다. 추론 전용 모델로 다시 변환하지 않아 학습 체크포인트의 원래 내용을 보존합니다.

## 제외한 자료

Isaac Sim 실행 파일, 외부 USD 로봇 에셋, Python/Conda 환경, 대형 terrain cache, 전체 개인 작업 폴더, 인증 정보, 시뮬레이터 전체 로그와 TensorBoard binary event는 포함하지 않습니다. 공개 코드의 원 저작권 고지를 유지하고 기반 프로젝트의 BSD-3-Clause 라이선스를 포함했습니다. 참고 프로젝트에서는 문서 구성 방식을 참고했으며 모델이나 결과를 가져오지 않았습니다.

설정 파일의 로컬 작업 경로는 `${ISAACLAB_ROOT}`로, 평가 JSON의 checkpoint 절대 경로는 공개 저장소의 상대 경로로 바꿨습니다. 측정 수치와 seed는 수정하지 않았습니다. 1차 평가의 원시 에피소드별 배열은 당시 평가기가 저장하지 않았으므로 공개 자료에도 없습니다. 새 보상 비교부터는 개체별 첫 에피소드 배열, 초기 상태·체크포인트·평가기 코드 해시를 함께 저장합니다. 이전 평가의 분산을 새 자료로 추정하거나 합치지 않습니다.

## 검증 방법

- 고정한 기반 커밋의 원본 파일에 patch를 적용하고 결과 12개 파일을 `overlay/`와 byte 단위로 대조.
- 모든 공개 Python 파일의 문법 검사와 평가 스크립트의 실제 GPU 실행.
- 초기 평가 3,072개, 최종 보상 검증 4,096개의 첫 에피소드 결과를 보존하고 본문에서는 대표 모델에 해당하는 비교만 표시.
- 모델 해시, 에피소드 수, 낙상 수와 완주율의 일관성, 지표 유한성, 집계 평균 재계산.
- 그래프가 저장된 결과에서 생성되는지 확인하고 출력 그림을 직접 검토.

새 보상 비교는 원래 측정값을 보존하고 `results/rewards/`에 별도로 기록합니다. 개발 지도와 최종 지도도 분리했습니다. 이 저장소의 결과는 작성 시점의 단일 학습 seed에 대한 실험 기록입니다.
