# 중간 실험과 검증 기록

프로젝트 본문은 [평지 모델 → 험지 모델 → 추가 학습 모델](../../README.md)의 세 단계로 구성한다. 이 문서는 그 사이의 보상 탐색·대조군·디버깅·원자료를 모은 기록이다.

2026-10-01부터 본문의 대표 결과는 [세 모델 공통 평가](../RESULTS.md)(seed 5001~5005)다. 아래 2001/2002 및 4001/4002 결과는 이전 실험 기록이며 새 평균에 포함하지 않는다.

## 모델 이름 구분

| 구분 | 파일 | 역할 |
| --- | --- | --- |
| 대표 모델 | `flat.pt`, `rough.pt`, `recovery.pt` | 평지·험지·최종 추가 학습 모델 |
| 초기 보상 실험 | `stable.pt` | 액션 변화·각속도 패널티, 300회 추가. 생존율 개선이 일관되지 않아 중간 실험으로 분류 |
| 강한 패널티 실험 | `strong.pt`, `strong_100.pt` | 과도한 감점으로 성능이 낮아진 실험과 중간 체크포인트 |
| 동일 예산 대조군 | `control.pt` | 원래 보상을 유지하고 600회 추가 학습해 최종 보상과 비교 |

`stable.pt`는 본문에서 말하는 최종 추가 학습 모델이 아니다. 최종 모델은 `recovery.pt`이며 `rough.pt`에서 직접 시작했다. `stable.pt`나 `control.pt`를 이어 학습한 모델이 아니다.
