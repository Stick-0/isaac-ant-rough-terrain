# 개발 과정과 실패에서 배운 점

## 1. 원본 평지 정책

2026-09-17에 원본 `Isaac-Ant-v0`의 평지 정책을 seed 42, 1,000회 학습했습니다. 이 체크포인트와 당시 환경·PPO YAML을 보존해 이후 험지 정책의 비교 기준으로 사용했습니다.

## 2. 지형 생성과 배치

2026-09-27에 평면을 랜덤 요철·파도·경사 지형으로 바꿨습니다. 테두리를 없애고, generated terrain의 tile-origin 배치 대신 기존 5m 격자 배치를 유지하도록 구현했습니다. 타일 정점을 연결하고 지형 위 시작 높이를 보정했습니다.

실험 중 지도 크기를 조정했고 최종 학습·평가 설정은 720×720m입니다. 이 크기는 최적 면적을 탐색한 결과가 아닙니다. 실제 설정과 보존한 로그를 일치시키기 위해 최종 값을 그대로 공개했습니다.

## 3. 제자리에서 반복 리셋되는 문제

초기에는 액션과 속도 값이 존재해도 출발점에서 거의 벗어나지 못했습니다. 다음 문제를 구분해 수정했습니다.

- 지형의 높이를 무시한 시작 Z와 높이 기반 관측·종료 판정.
- RayCaster와 복제 환경의 인덱스 버퍼 불일치.
- 대형 지형 메시의 PhysX cooking 실패.
- 테두리 폭 0에서도 만들어지는 퇴화 삼각형.
- 너무 많은 전역 collider 또는 넓은 bounding box에 따른 GPU 메모리 부담.

수정 후 4,096개 환경의 짧은 학습과 16초 재생을 실제 GPU에서 검증했습니다. 보존된 재생 진단 발췌는 [`physics_after.txt`](../results/diagnostics/physics_after.txt)에 있습니다. 이 짧은 진단은 충돌·리셋 문제 확인용이며, 이후 정책 성능 평가와 합산하지 않았습니다. 수정 전후의 정책과 조건이 동일한 통제 실험도 아닙니다.

## 4. 험지 모델 학습

충돌 수정 후 seed 42, 1,000회 학습한 체크포인트를 `rough.pt`로 공개했습니다. 원본과 같은 PPO 구조·학습 예산으로 지형에 적응하는 것을 우선 목표로 삼았습니다.

## 5. 안정성 보상 두 가지 강도 비교

첫 실험은 action-rate `-0.01`, body-sway `-0.025`와 낮은 고정 학습률로 300회 추가 학습했습니다. 초기 시드 1001/1002에서는 전진 거리와 액션 변화가 소폭 개선됐지만 몸통 흔들림 개선은 확인되지 않았습니다.

두 번째는 패널티를 각각 `-0.05`, `-0.1`로 높여 같은 rough 모델에서 200회 학습했습니다. 시드 1001의 완주율이 90.23%에서 중간 모델 87.11%, 최종 모델 89.06%로 떨어졌습니다. 강한 패널티가 곧 더 좋은 보행을 뜻하지 않는 사례로 보존했습니다.

초기의 상세 기록은 [`2026-09-27_stability.md`](2026-09-27_stability.md)입니다. 이 문서의 “기존 모델”은 원본 평지 모델이 아니라 **당시의 험지 모델**입니다.

## 6. 원본과의 비교 보강

2026-09-29에 저장소 공개를 준비하면서 원본 평지 체크포인트를 검증하고, 고정한 세 모델을 새 지형 seed 2001/2002에서 평가했습니다. 험지 학습의 효과와 추가 안정성 보상의 효과를 구분할 수 있게 됐습니다.

평지→험지의 완주율 차이는 컸지만, 추가 보상의 완주율 개선은 시드별 방향이 달랐습니다. 그래서 험지 모델을 기본 데모 모델로 두고 추가 학습 모델은 비교 대상으로 공개합니다. 실패한 실험을 성공 사례로 바꾸거나 유리한 시드만 골라 보고하지 않았습니다.

## 다음 실험으로 남겨 둔 것

여러 학습 seed, 같은 추가 학습 예산의 기존 보상 대조군, 평지 성능 유지율, 더 긴 에피소드와 새 지형 종류의 검증이 필요합니다. 현재 성과에 포함하지 않은 후속 과제입니다.

## 2026-09-29: 보상 재설계와 동일 예산 대조군

기존 Stable의 생존율 개선이 일관되지 않아 낙상 사건 -10, 지면 상대 몸높이·기울기 위험 감점, 4.5m/s 전진 보상 상한을 추가했다. `Isaac-Ant-Recovery-v0`를 별도로 등록해 이전 실험을 재현할 수 있게 했다.

원래 보상 대조군과 새 보상 모델을 같은 rough 가중치에서 각각 600회 학습했다. 개발 seed 3001 평가 후 설정을 변경하지 않았으며, 최종 seed 4001/4002에서 대조군 대비 생존율 +4.79%p, 낙상 47.12% 감소를 확인했다. 속도 5.47%, 거리 3.58% 감소도 함께 기록했다. 결과를 과거 seed의 평균에 섞지 않았다.

새 평가기는 개체별 첫 에피소드와 초기 상태·모델·평가기 해시를 저장한다. 보상 경계 조건 6개, 실제 GPU 학습·평가, 동일 설정 비교, 원본 패치 적용을 검사했다. [전체 결과와 한계](REWARD_RESULTS.md).

## 2026-10-01: 세 대표 모델의 공통 지형 재평가

평지·험지 비교와 험지·추가 학습 비교가 서로 다른 평가 지형을 사용하던 본문 구성을 교체했다. 세 모델을 고정한 채 새 seed 5001~5005에서 모델별 2,560개 첫 에피소드를 평가했고, 모든 시드에서 세 모델의 초기 상태 해시 일치를 확인했다. 생존율은 평지 16.17%, 험지 90.51%, 추가 학습 95.00%다. 추가 학습 모델의 낙상은 험지 대비 47.3% 줄었고, 속도는 4.2% 낮았다.
