# Ant 보행 안정성 추가 학습

`Isaac-Ant-Stable-v0`는 현재의 울퉁불퉁한 `Isaac-Ant-v0`를 기반으로 한다.
60차원 관측, 토크 제어, 지형, 개미 배치, 종료 조건은 같아서 기존 모델을 불러올 수 있다.

추가한 보상은 두 가지다.

| 항목 | 계산 | 가중치 |
| --- | --- | --- |
| 액션 변화 | 직전 액션과 현재 액션 차이의 제곱합 | -0.01 |
| 몸통 흔들림 | 몸통 좌표계 roll/pitch 각속도의 제곱합 | -0.025 |

기존 전진·생존·자세 보상은 유지한다. PPO 학습률은 `0.0001`로 고정하고,
엔트로피 계수 `0.001`로 작은 탐색을 허용한다. 기본 추가 학습량은 300회다.
이 단계에서는 마찰·질량 랜덤화나 지형 스캔 관측을 추가하지 않는다.

## 기존 모델에서 추가 학습

저장소 루트에서 실행한다. `--warm_start`는 정책·가치망 가중치를 불러오고,
옵티마이저와 반복 횟수는 새로 시작한다. `--resume`과 함께 사용할 수 없다.

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/train.py \
  --task Isaac-Ant-Stable-v0 --headless --seed 42 \
  --warm_start logs/rsl_rl/ant/2026-09-27_17-02-03/model_999.pt \
  --max_iterations 300 --run_name stability_finetune
```

결과는 `logs/rsl_rl/ant_stable/`에 저장한다. 이후 같은 실험을 계속 학습할 때는
`--warm_start` 대신 `--resume --load_run <실험폴더명>`을 사용한다.

## 동일 조건 비교

다음 명령의 체크포인트 경로를 실제 파일 경로로 바꾼다.

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/evaluate_ant.py \
  --headless --seed 1001 --num_envs 512 \
  --checkpoints <기존모델.pt> <개선모델.pt> \
  --output /tmp/ant_comparison_1001.json
```

같은 명령을 `--seed 1002`로도 실행한다. 비교하는 모델에는 동일한 지형과
동일한 초기 상태 난수를 적용하며, 정책의 탐색 노이즈는 끈다.
각 개미의 첫 에피소드만 측정한다. 생존율은 넘어지지 않고 16초 제한에 도달한 비율이다.
전진 거리는 자동 재시작 직전 관측 위치를 사용하므로 마지막 한 스텝까지의 이동은 제외한다.
흔들림과 액션 변화량은 개미별 RMS를 구한 뒤 평균한다.

성능은 생존율·전진 거리·속도와 안정성 지표를 함께 비교한다.
평가에 사용한 지형 시드에서의 결과가 모든 새로운 환경에서의 성능을 보장하지는 않는다.

## 재생

```bash
./isaaclab.sh -p scripts/reinforcement_learning/rsl_rl/play.py \
  --task Isaac-Ant-Stable-v0 --num_envs 64 \
  --load_run 2026-09-27_17-39-34_stability_finetune --diagnostics
```

## 실제 검증 결과 (2026-09-27)

기존 모델은 `logs/rsl_rl/ant/2026-09-27_17-02-03/model_999.pt`,
선택한 추가 학습 모델은
`logs/rsl_rl/ant_stable/2026-09-27_17-39-34_stability_finetune/model_299.pt`다.
추가 학습은 4,096개 환경에서 300회, 총 39,321,600 환경 스텝을 실행했다.

시드 1001은 설정 선택용으로 사용했고, 시드 1002는 모델 선택 후 별도로 평가했다.
각 시드에서 모델별 512개 환경의 첫 16초 에피소드를 평가했다.

| 지표 | 1001 기존 | 1001 추가 학습 | 1002 기존 | 1002 추가 학습 |
| --- | ---: | ---: | ---: | ---: |
| 16초 완주율 | 90.23% | 91.02% | 92.77% | 92.77% |
| 평균 관측 전진 거리 (m) | 67.49 | 68.51 | 69.26 | 69.60 |
| 평균 전진 속도 (m/s) | 4.343 | 4.375 | 4.410 | 4.434 |
| roll/pitch 각속도 RMS (rad/s) | 2.051 | 2.057 | 2.048 | 2.059 |
| 관절당 액션 변화 RMS | 0.3298 | 0.3264 | 0.3308 | 0.3258 |

별도 평가에서 전진 거리는 약 0.5% 증가했고 액션 변화는 약 1.5% 감소했다.
완주율은 같고 몸통 각속도 RMS는 약 0.5% 증가했다.
따라서 전진과 액션 변화의 소폭 개선은 관측했지만,
넘어짐이나 몸통 흔들림의 뚜렷한 개선은 확인하지 못했다.
한 번의 학습 실행 결과이며 통계적으로 확실한 향상을 입증한 것은 아니다.

원시 측정값과 실행 로그는 선택한 실험 폴더의 `evaluation/seed_1001.json`,
`evaluation/seed_1002.json` 및 같은 이름의 `.log` 파일에 저장했다.
