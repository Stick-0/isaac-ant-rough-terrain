# 세 모델의 실험 조건

## 모델과 학습량

| 모델 | 환경·목적 | 학습 seed | 반복 횟수 | 환경 transition 수 |
| --- | --- | ---: | ---: | ---: |
| 평지 `flat.pt` | 원본 평지의 기준 보행 | 42 | 1,000 | 131,072,000 |
| 험지 `rough.pt` | 랜덤 험지 적응 | 42 | 1,000 | 131,072,000 |
| 추가 학습 `recovery.pt` | 험지 보행 안정성 개선 | 42 | rough에서 600 추가 | 추가 78,643,200 |

환경 4,096개 × rollout 32스텝 × 반복 횟수다. 평지와 험지는 각각 학습했으며, 추가 학습은 험지의 actor·critic·policy noise 파라미터에서 출발해 새 optimizer를 사용한다.

세 모델은 관측 60D, 토크 액션 8D, actor·critic `[400, 200, 100]` ELU MLP를 사용한다. 물리 dt는 1/120초, 제어 dt는 1/60초, 에피소드 제한은 16초다. 평지·험지의 초기 학습률은 5e-4 adaptive, 추가 학습은 1e-4 고정과 entropy 0.001이다. [실제 설정](../configs/runs), [체크포인트 해시](../manifest.json).

## 세 모델의 공통 평가

2026-10-01에 세 대표 모델을 같은 새 지형에서 재평가했다. 기존 2001/2002와 4001/4002의 서로 다른 비교를 본문 수치로 쓰던 구성을 이 공통 평가로 교체했다.

| 항목 | 조건 |
| --- | --- |
| 모델 | 평지 `flat.pt`, 험지 `rough.pt`, 추가 학습 `recovery.pt` |
| 지형 seed | 5001, 5002, 5003, 5004, 5005 |
| 모델별 표본 | 시드별 512마리 × 5개 지형 = 2,560개 첫 에피소드 |
| 전체 표본 | 3개 모델 × 2,560 = 7,680개 첫 에피소드 |
| 평가 환경 | 공통 `Isaac-Ant-v0` 험지 환경, 최대 16초 |
| 행동 | 탐색 노이즈 없이 actor 평균 액션 |
| 시작 상태 | 모델마다 같은 seed로 리셋하고 몸통·관절 상태 SHA-256 일치 확인 |

평가 전에 [프로토콜](../results/models/protocol.json)에 시드, 모델 해시, 평가기 해시, 전체 표본 사용 원칙을 고정했다. 결과를 보고 시드나 체크포인트를 고르거나 추가 학습하지 않았다. 한 시드 안에서는 동일하게 생성한 지형 인스턴스를 공유하며, 평지 → 험지 → 추가 학습 순서로 평가한다. 모델마다 리셋 seed를 다시 설정한다.

세 모델은 같은 지형·격자 원점·초기 관절 상태·관측 변환·종료 조건을 사용한다. 각 개체의 첫 에피소드만 집계하고 자동 리셋 이후는 제외한다. 평지 모델은 원래 절대 Z 관측으로 학습했지만 험지 평가에서는 공통 지면 상대 높이 관측을 입력한다. 따라서 원본 관측을 그대로 둔 평지 정책의 평가와는 구분한다.

학습 seed 42, 개발 지형 3001, 이전 비교의 지형 2001/2002 및 4001/4002는 이번 다섯 지형 평균에 포함하지 않는다. 기존 측정값과 동일 예산 대조 실험은 [과거 기록](archive/README.md)에서 확인할 수 있다.

## 지표

- 생존율: 첫 에피소드에서 낙상 없이 16초 timeout에 도달한 비율. 특정 경로의 끝에 도달한 비율이 아니다.
- 전진 거리: 최초 위치 대비 마지막 관측의 월드 X 변위. 자동 리셋 직전 마지막 한 제어 스텝은 빠질 수 있다.
- 전진 속도: 생존 중 월드 X 속도의 개체별 시간 평균을 구한 뒤 전체 개체 평균.
- 액션 변화 RMS: 관절당 연속 액션 차이의 개체별 RMS를 구한 뒤 평균. 첫 액션은 0과 비교한다.
- 몸체 각속도 RMS: 몸통 좌표계 roll/pitch 각속도 제곱합의 시간 RMS를 구한 뒤 개체 평균. 자세 각도 자체나 발 미끄러짐 지표는 아니다.

이번 다섯 시드의 JSON에는 모든 개체의 생존·낙상·거리·속도·몸체 각속도·액션 변화 배열과 초기 상태·모델·평가기 코드 해시를 저장했다. 전체 평균은 각 개체를 동일한 비중으로 집계하며, 그래프의 점은 지형별 평균이다. 점은 신뢰구간이 아니다.

## 해석 범위

학습 seed는 하나이며 새 지형도 같은 생성 분포에서 뽑았다. 실세계·물성 변화·센서 노이즈·지연 등에 대한 검증은 아니다. 영상은 별도의 16환경 데모다.

험지 모델은 지형·관측·충돌·종료 조건을 함께 바꾼 결과이고, 추가 학습 모델은 리워드와 추가 학습량이 함께 적용된 결과다. 각 변경의 단독 효과를 뜻하지 않는다. 추가 학습량을 맞춘 보상 대조 실험과 개체별 대응 분석은 [별도 검증 기록](archive/reward_comparison.md)에 정리했다.

낮은 몸체 RMS 하나만으로 안정성을 판단하지 않는다. 특히 빨리 넘어지는 모델은 긴 보행 구간을 경험하지 못할 수 있다. 서로 다른 보상 함수의 학습 총점도 성능 순위에 사용하지 않는다.
